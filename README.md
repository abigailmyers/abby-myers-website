# Abby Myers Personal Portfolio Website

A personal portfolio website presenting my background, skills, professional experience, contact information, resume, and featured project work. The website serves as a professional online presence for recruiters, collaborators, and visitors to learn about my qualifications and career interests in Information Systems and Analytics.

**Live Website:** [https://abigailmyers.github.io/abby-myers-website/](https://abigailmyers.github.io/abby-myers-website/)

---

## Website Structure

This website uses a three-page hybrid structure:

* **`index.html` (Homepage)**: Features an introduction (Profile), technical and professional skills, work experience, and contact details with anchor-linked sections.
* **`resume.html` (Resume)**: Expands into a formal resume format detailing education at Louisiana State University, detailed professional experience, competencies, and professional affiliations.
* **`project.html` (Featured Project)**: Presents a detailed project case study describing the background, goals, role, process, tools, results, and lessons learned from designing and building this portfolio.

## Local Development & Viewing

To view the website locally on your computer:

1. Clone or download this repository to your local machine.
2. Navigate to the project directory.
3. Open `index.html` directly in any modern web browser (e.g., double-click the file, or right-click and choose "Open With" your preferred browser).

## File Structure

```text
abby-myers-website/
├── index.html     # Homepage containing Profile, Skills, Experience, and Contact sections
├── resume.html    # Detailed resume page covering education, experience, skills, and activities
├── project.html   # Case study page detailing the featured portfolio website project
├── styles.css     # Shared stylesheet controlling design system, responsive layout, and accessibility
└── README.md      # Project documentation and repository overview
```

* **`index.html`**: The main entry point featuring the profile overview, core skills, recent experience, and contact information.
* **`resume.html`**: A dedicated resume page expanding on educational background, coursework, work history, competencies, and activities.
* **`project.html`**: A comprehensive project case study outlining the problem, role, workflow, and outcomes of creating this website.
* **`styles.css`**: A single shared stylesheet establishing design tokens, typography, navigation, card components, focus rings, and mobile media queries.

---

## Development Process

The website was built through an iterative, step-by-step development process:

1. **Structure**: Established the core semantic HTML structure for the three-page hybrid layout and shared stylesheet.
2. **Real Content**: Replaced draft placeholders with authentic educational history, professional background, skills, and project documentation.
3. **Responsive & Accessibility Improvements**: Refined navigation touch targets, audited keyboard focus indicators, verified color contrast ratios, resolved sticky header anchor offsets, added skip links, and ensured proper wrapping for long URLs and unbroken content on narrow screens.
4. **Visual Refinement**: Polished typography, consistent spacing, clean active navigation indicators, and cross-device usability.

---

## Reflection

I learned that responsive design requires more than making a desktop layout smaller. Navigation spacing, long links, sticky headers, readable contrast, keyboard focus indicators, and narrow-screen testing all affect whether a website is genuinely usable. I also learned to review AI-generated code carefully, test each change, and use descriptive Git commits to preserve a clear development history.
