Personal Portfolio Website

Project Overview

This project involved designing and developing a personal portfolio website to present my education, skills, professional experience, contact information, resume, and featured work. The website was created as an individual project for ISDS 4125 at Louisiana State University.

Problem or Goal

The goal was to create a professional online presence that allows recruiters and other visitors to quickly understand my background, abilities, and career interests. The website also needed to be responsive, easy to navigate, and publicly accessible.

My Role

I completed the project individually. I planned the website structure, directed the AI coding agent, reviewed the generated code, provided the content, tested the pages and navigation, and managed the project through Git and GitHub.

Process

I began by identifying the assignment requirements and creating the required HTML and CSS files. I then used Google Antigravity to generate the initial structure, reviewed the code, tested the website locally, replaced the placeholder text with real content, and used Git commits to document the development process. The final steps included testing the website on different screen sizes and publishing it through GitHub Pages.

Skills or Tools

  • HTML & CSS
  • Google Antigravity IDE
  • Git & GitHub
  • GitHub Pages
  • Responsive Web Design & Iterative Testing

Results

The final deliverable is a three-page responsive personal website containing a single-page homepage, a resume page, and a detailed project page. The source code is stored in a public GitHub repository, and the completed website is publicly available through GitHub Pages.

Lessons Learned

I learned how separate HTML pages share a CSS stylesheet, how navigation links connect pages and page sections, and how Git and GitHub preserve a history of website changes. I also gained experience directing an AI coding agent while reviewing and maintaining ownership of the generated code.
